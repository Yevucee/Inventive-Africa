# Inventive Africa site

The Astro site is a local preview of the published WordPress content. Work from the repository root and follow [the main README](../README.md) for import and build commands.

The imported articles are in `src/content/posts/`, the published About page is in `src/content/pages/`, and the media used by those pages is in `public/wp-content/uploads/`. The original WordPress XML and media archive remain outside Git.

The existing WordPress site remains live. This preview is not a launch approval.
